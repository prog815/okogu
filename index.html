ОКОГУ

Общероссийский классификатор органов государственной власти и управления. Поиск по коду, наименованию и сокращению: МВД, ФСБ, Росстат, ФНС, Центральный банк, ВЭБ.РФ, Сбербанк и другим органам и организациям. Справочник плоский — с разделами вместо дерева.

Поиск по коду выполняется с начала кода. Поиск по названию и сокращению поддерживает несколько слов. Кликните по коду или сокращению, чтобы скопировать его.

Загрузка статистики…
Справочник носит информационный характер. Для официального применения сверяйтесь с действующей редакцией ОКОГУ. Данные обновляются ежедневно из официального открытого набора Росстата. Иерархия (родитель/ребёнок) в источнике отсутствует — отображаются только разделы.
